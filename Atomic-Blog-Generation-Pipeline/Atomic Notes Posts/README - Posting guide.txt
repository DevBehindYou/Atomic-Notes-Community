ATOMIC NOTES POSTS: POSTING GUIDE
Source: topics/Posts List 01 - AtomicNotes.txt (40 posts). Prepared October 4, 2026.

WHAT'S HERE
- X/        10 posts. Each folder: post.txt (paste as is), image.png (attach), notes.txt (length, alt text).
- Reddit/   10 posts. Each folder: title.txt, body.md (paste in Markdown mode), notes.txt (where to post and why).
- Patreon/  10 posts. Each folder: title.txt, post.txt, banner.png, notes.txt (alt text, audience tip).
- Ko-fi/    10 posts. Each folder: title.txt, post.txt, banner.png, notes.txt (alt text).

Images are 2000x1125 (16:9). That fits X's in-feed preview and works as a header image on Patreon and Ko-fi.
Reddit posts carry no image on purpose: discussion posts do better as plain text there.

WHAT I CHANGED FROM THE LIST, AND WHY
1. "Open source" is gone everywhere. Atomic Notes is source-available (Atomic Notes Source-Available License),
   not open source. Every tagline, hashtag and claim now says "public code" or "source-available".
   - Tagline "Open source. Local first. Private by design." is now "Local first. Private by design. ⚛️"
   - X 7, Reddit 7, Patreon 9 and Ko-fi 10 now explain source-available honestly:
     you can read, audit and build the code to verify it, but not reuse it.
   - #OpenSource hashtags were removed.
2. X posts now fit the 280-character limit (weighted count: links count 23, emoji count 2). Each notes.txt shows the count.
3. Facts now match the app (version 2.03.5):
   - The vault is optional and off by default.
   - With the vault off, note text passes through the server on its way to Drive, without being stored.
   - The app only sees the Drive files it created (drive.file).
   - Energy: +20 a day, up to 120. Automatic sync costs 5, instant sync costs 10. A sync with nothing to upload is free, and a failed sync is refunded.
   - Reddit 4 now mentions the 30-note free limit. Its old title said note taking was "completely free", which wasn't exact.
   - Reddit 10 lists everything the server keeps, taken from the privacy policy.
4. Style rules: no em dashes, no semicolons, no banned words, active voice.
   "Privacy is not only about..." lines were rewritten (X 8, Ko-fi 9).

PLATFORM NOTES
- X: attach image.png and paste the alt text from notes.txt. If link posts get less reach, post without the link
  and add it as the first reply.
- Reddit: read each subreddit's self-promotion rules first. Post to one subreddit at a time, a few days apart, and
  answer comments quickly. Avoid:
  - r/opensource: the app is source-available.
  - r/privacy: it bans self-promotion.
  - r/degoogle: Google sign-in would draw criticism.
- Patreon: make these public posts, so new visitors see them. Patreon 10 mentions that supporters get Atomic Coins
  early, which matches the support page.
- Ko-fi: the website's support page links to Patreon only. Publish the Ko-fi posts only if you keep an active
  Ko-fi page. Otherwise, reuse them as extra Patreon posts or website updates.

SUGGESTED RHYTHM (about 5 weeks)
- X: 2 posts a week.
- Reddit: 1 post a week, in a different subreddit each time.
- Patreon: 2 posts a week.
- Ko-fi: 2 posts a week, if used. Run the same theme a few days after its Patreon version.
Start with the themes that explain the product: local first (X 1, X 5, Reddit 3, Patreon 1), your own Drive
(X 3, Reddit 1, Patreon 2) and no AI (X 2, Reddit 2, Patreon 5).
