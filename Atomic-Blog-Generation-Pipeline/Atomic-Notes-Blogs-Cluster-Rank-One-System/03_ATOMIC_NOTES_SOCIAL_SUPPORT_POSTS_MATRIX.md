# Atomic Notes Social Support Posts Matrix

## Purpose

This file contains **platform-specific post briefs** for all 45 Support Blogs.

The AI Agent must turn each brief into final original copy.

Every Support Blog gets:

• X.com  
• LinkedIn  
• Instagram  
• Reddit  
• Threads  
• Facebook  
• Pinterest  
• Bluesky

That creates 360 social support posts.

The primary social link target is the **Support Blog**, not the Main Blog. The Support Blog then links contextually to its Main Blog.

Do not copy the same caption across platforms.

## Platform Rules

### X.com
Use a concise insight, contrarian observation, checklist, or question. Usually 1 to 3 short paragraphs. Use 0 to 3 relevant hashtags.

### LinkedIn
Use a professional privacy/security/software-engineering angle. Explain the insight before the CTA.

### Instagram
Create a carousel or Reel brief. First slide must be a strong hook. Add 4 to 7 educational frames, caption CTA, and useful alt text.

### Reddit
Write a discussion-first post that stands alone. Mention project involvement transparently. Follow subreddit self-promotion rules. If linking is not allowed, do not force the link.

### Threads
Use a conversational hook and one memorable takeaway. Keep it lighter than LinkedIn.

### Facebook
Use an accessible educational post with a checklist or question.

### Pinterest
Create a search-friendly visual title and infographic/checklist concept. Link the Pin to the Support Blog.

### Bluesky
Concise open-web, privacy, or architecture angle. Avoid hashtag stuffing.

# Required CTA and Tracking Convention

Use the Support Blog URL as the CTA destination.

Recommended social UTM format:

`?utm_source={platform}&utm_medium=social&utm_campaign={pillar}-{main_id}&utm_content={support_id}`

Examples:

`utm_source=x`
`utm_source=linkedin`
`utm_source=instagram`
`utm_source=reddit`
`utm_source=threads`
`utm_source=facebook`
`utm_source=pinterest`
`utm_source=bluesky`

Do not add UTM parameters to editorial backlinks from Support Blogs to Main Blogs unless there is a clear analytics need. Keep editorial destination URLs clean where possible.

# Existing Posts Reuse Rule

Posts from `Posts List 01` can be used as seed ideas when they naturally match a campaign, but the final post must be refreshed for:

• current facts
• current URL
• current Support Blog CTA
• current platform norms
• current audience

Never blast the same existing post to all networks unchanged.
